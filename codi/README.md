# 오늘뭐입지 — AI 코디 추천 웹앱

내 옷 사진을 올리면 AI(Claude)가 옷장을 자동으로 정리하고, 서울 날씨에 맞춰 매일 코디를 추천해 주는 웹앱입니다.

## 기능
- **옷장 등록**: 사진 여러 장을 한 번에 올리면 종류·색·소재·계절·보온성·격식을 자동 분석해서 저장 (한 장에 여러 벌이면 각각 등록). 탭해서 수정/삭제 가능.
- **오늘 코디**: 서울 날씨(Open-Meteo, 아침/낮/저녁 기온·체감·강수확률)와 상황(출근, 데이트 등)을 반영해 코디 2~3개 추천. 옷장에 없어서 아쉬운 아이템도 알려줌.
- **트렌드 검색(선택)**: 체크하면 요즘 데일리룩 트렌드를 웹에서 검색해 반영.
- **착용 기록**: "이걸로 입을게"로 기록하면 최근 7일간 입은 조합은 피해서 추천.
- **백업**: 옷장 데이터를 JSON으로 내보내기/불러오기.

## 사용법
1. 이 폴더를 정적 호스팅에 올리기 (예: GitHub Pages → Settings → Pages에서 브랜치 지정 후 `/codi/` 경로로 접속).
   로컬에서는 `cd codi && python3 -m http.server` 후 http://localhost:8000
2. 폰으로 접속 → 공유 → **홈 화면에 추가**하면 앱처럼 사용.
3. 설정 탭에 Anthropic API 키 입력 (https://console.anthropic.com/settings/keys).
4. 옷장 탭에서 옷 사진 추가 → 오늘 코디 탭에서 추천받기.

## 참고
- 서버 없이 브라우저에서 바로 Claude API를 호출합니다. API 키와 옷장 데이터는 **그 기기 브라우저에만** 저장돼요. 개인용으로만 쓰고 공개 배포 시 다른 사람과 키를 공유하지 마세요.
- 모델: `claude-opus-5-5` (사진 분석은 effort `low`, 코디 추천은 `medium`). 거절 응답 시 서버 측 fallback 사용.
- 비용: 사진 분석은 장당 몇 원 수준, 코디 추천은 옷장 크기에 따라 회당 수십 원 수준(트렌드 검색 시 추가).
